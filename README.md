# Номера банковских карт

Лабораторная работа № 2 по дисциплине «Прикладное программирование»:
«Регулярные выражения. Unit-тестирование».
Вариант 13 — проверка и поиск синтаксически корректных номеров банковских карт.

## Возможности

- проверка номера карты, введённого пользователем;
- поиск номеров карт в текстовом файле;
- поиск номеров карт на веб-странице по URL;
- определение платёжной системы (Visa, Mastercard, МИР) и запись номера без разделителей.

Номер считается корректным, если:

1. в нём ровно 16 цифр;
2. он начинается с `4` (Visa), `51`–`55` (Mastercard) или `2200`–`2204` (МИР);
3. он записан слитно или группами по 4 цифры;
4. группы разделены только пробелами или только дефисами.

При ошибках (несуществующий файл, неверный URL, нет соединения)
программа не завершается, а выводит сообщение и возвращается в меню.

## Запуск

Нужен Python 3.10 или новее и библиотека `requests`.
Запускать из папки проекта:

```bash
python -m pip install -r requirements.txt
python main.py
```

Запуск тестов:

```bash
python -m unittest -v
```

## Устройство программы

| Файл | Функции | За что отвечает |
|---|---|---|
| `main.py` | `main`, `check_card`, `search_in_file`, `search_in_url` | Точка входа и меню |
| `card_regex.py` | `is_valid_card`, `find_cards`, `normalize_card`, `get_payment_system` | Регулярное выражение, проверка и поиск номеров |
| `card_regex.py` | `find_cards_in_file`, `find_cards_in_url` | Чтение файла и загрузка веб-страницы |
| `test_card_regex.py` | классы `TestIsValidCard`, `TestFindCards`, `TestOtherFunctions`, `TestSources` | Unit-тесты на `unittest` |

Вся работа с регулярным выражением собрана в `card_regex.py`, а меню в `main.py`
только вызывает эти функции, поэтому их можно проверять тестами отдельно от ввода с клавиатуры.

## Структура проекта

```
├── main.py               точка входа, консольное меню
├── card_regex.py         регулярное выражение и функции поиска
├── test_card_regex.py    unit-тесты
├── cards_example.txt     пример файла с номерами карт
└── requirements.txt      внешние библиотеки
```

## Тестовые данные

| Что | Значение |
|---|---|
| Visa | `4111111111111111` |
| Mastercard | `5555 5555 5555 4444` |
| МИР | `2200-1234-5678-9010` |
| Некорректный (неизвестная платёжная система) | `1234 5678 9012 3456` |
| Некорректный (разные разделители) | `4111 1111-1111 1111` |
| Файл для поиска | `cards_example.txt` (4 корректных номера) |
